# De patria a patria

## Descripción

Sitio web responsivo desarrollado como parte del Proyecto 6 del curso de desarrollo web. Presenta una galería digital que destaca los lugares de origen de distintos colaboradores, usando una narrativa visual y textual atractiva.

## Propósito

Demostrar habilidades en HTML, CSS responsivo y aplicación de la metodología BEM, respetando los lineamientos de un diseño profesional en Figma para diferentes resoluciones.

## Tecnologías utilizadas

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- Metodología BEM
- Editor: Visual Studio Code

## Instalación y uso local

Clona el repositorio:

```bash
git clone https://github.com/Gaboobga/web_project_homeland
```

https://gaboobga.github.io/web_project_homeland/

## Validaciones

- Código HTML validado con W3C Validator.
- Cumple con el diseño en resoluciones 1280px, 768px y 320px.
- Sin scroll horizontal en ninguna resolución.
